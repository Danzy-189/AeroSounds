# Aero Sounds

Аддон-звуковой движок для **Create: Aeronautics / Create Simulated** (Minecraft 1.21.1, NeoForge).

Добавляет реалистичную аэродинамическую звуковую картину физических построек: свист рассекаемого
воздуха у движущихся машин и самолётов, «вжух» при пролёте рядом, дрожащий гул на околозвуковой
скорости и **звуковой удар** при переходе через скорость звука — с эффектом Доплера, конечной
скоростью распространения звука, поглощением в воздухе и затуханием за препятствиями.

Мод полностью **клиентский**: сервер и другие игроки ему не нужны.

---

## Что именно слышно

| Звук | Когда возникает |
|---|---|
| `wind_light` | лёгкий свист воздуха, как только постройка разгоняется выше `windMinSpeed` (6 бл/с) |
| `wind_heavy` | низкий гружёный рёв, кроссфейдом подмешивается по мере разгона и роста площади миделя |
| `wind_cabin` | ветер «изнутри», когда вы сами едете/летите на постройке; в закрытом корпусе тише |
| `whoosh_pass` | одиночный «вжух» в момент наибольшего сближения быстрого объекта с вами |
| `transonic_rumble` | болтанка/бафет между M 0.85 и M 1.0 |
| `sonic_boom_near` / `sonic_boom_far` | звуковой удар, когда конус Маха доходит именно до вас |

## Физика звука

* **Конечная скорость звука.** Каждое событие ставится в очередь с задержкой `r / c`. Далёкий
  хлопок вы услышите через несколько секунд после того, как самолёт пролетел над головой.
* **Конус Маха, а не «таймер».** Для каждой постройки хранится след точек излучения. Каждый тик
  проверяется, дошла ли до слушателя волна, испущенная в тик `T`. Первая дошедшая волна и есть
  огибающая — конус Маха. Поэтому игрок, оставшийся вне конуса, хлопка не слышит вообще, а на один
  сверхзвуковой «забег» приходится ровно один удар.
* **Эффект Доплера.** `f' = f·(c + v_слушателя)/(c − v_источника)` по радиальной составляющей
  скоростей, с ограничением знаменателя, чтобы питч не взрывался на самом M 1.
* **Геометрическое расхождение.** Шум обтекания спадает как `1/r`, ударная N-волна — примерно как
  `r^-3/4`, как и в реальности.
* **Поглощение в воздухе.** С расстоянием уходят верхние частоты: громкость падает экспоненциально,
  питч слегка снижается, а для дальних ударов берётся отдельный «раскатистый» сэмпл с эхом от земли.
* **Плотность воздуха.** Выше ~160 блоков воздух разрежен — аэродинамический шум тише.
* **Окклюзия.** Луч от слушателя к источнику и обратно оценивает толщину преграды: за холмом и в
  бункере тише, за забором почти нет.
* **Своя модель громкости.** Minecraft связывает громкость и радиус слышимости в один параметр,
  поэтому мод считает усиление сам и проигрывает сэмпл в «прокси-точке» в 2 блоках от слушателя
  строго в направлении источника. Панорама и направление верные, а дальность и громкость — наши.
* **Относительность.** Все расчёты ведутся от камеры слушателя и её скорости, так что звук корректен
  и когда вы стоите на земле, и когда летите на соседнем самолёте.

## Как определяются физические постройки

Без жёсткой зависимости от API (Sable/Aeronautics меняются между версиями): объект считается
физическим, если его сущность принадлежит одному из пространств имён
`simulated, aeronautics, offroad, sable, create, valkyrienskies, vs_eureka`
либо имя её класса/идентификатора содержит `physics, contraption, ship, vehicle, aircraft`.
Оба списка редактируются в конфиге, так что мод работает и с будущими версиями, и с другими
физическими модами.

## Звуки

Сэмплы не записаны, а **синтезированы** скриптом `tools/generate_sounds.py`:

* петли ветра строятся прямо в частотной области — они математически бесшовные, без щелчка на стыке;
* «вжух» — это полосовой шум, центр которого едет вниз при пролёте, то есть Доплер вшит в сам сэмпл;
* звуковой удар — классическая N-волна: два скачка уплотнения, разделённые временем прохода
  корпуса, плюс раскат и отражения от земли для дальнего варианта.

Скрипт запускается автоматически при сборке (нужны `python3` + `numpy` + `ffmpeg`), либо вручную:

```bash
python3 tools/generate_sounds.py
```

## Сборка

```bash
gradle build          # или ./gradlew build, если сгенерировать wrapper: gradle wrapper
```

Готовый jar — в `build/libs/`. Также собирается автоматически в GitHub Actions
(вкладка **Actions → Build → aerosounds-jar**).

Требования: JDK 21, NeoForge 21.1.247, Minecraft 1.21.1.

## Конфиг

`config/aerosounds-client.toml`, все значения применяются на лету:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `masterVolume` | 1.0 | общая громкость мода |
| `speedOfSound` | 100 бл/с | скорость звука; 343 — реализм (в Minecraft недостижимо), 100 — игровой баланс |
| `propagationDelay` | true | задержка распространения звука |
| `doppler` / `dopplerStrength` | true / 1.0 | эффект Доплера и его усиление |
| `occlusion` / `occlusionStrength` | true / 0.7 | приглушение за препятствиями |
| `airAbsorption`, `altitudeDensity` | true | поглощение в воздухе и разрежённость на высоте |
| `windMinSpeed` / `windFullSpeed` | 6 / 70 бл/с | порог и точка максимума шума обтекания |
| `windMaxDistance` | 160 блоков | радиус слышимости ветра |
| `cabinWindVolume` | 0.9 | громкость ветра «изнутри» постройки |
| `whooshMaxMissDistance` / `whooshMinSpeed` | 26 / 18 | условия «вжуха» при пролёте |
| `boomVolume` / `boomMaxDistance` | 1.0 / 400 | звуковой удар |
| `boomCooldownTicks` | 30 | минимум тиков между ударами от одного объекта |
| `transonicRumble` | true | околозвуковая болтанка |
| `namespaces` / `classNameHints` | см. выше | что считать физической постройкой |
| `includeVanillaVehicles` | false | озвучивать вагонетки и лодки |
